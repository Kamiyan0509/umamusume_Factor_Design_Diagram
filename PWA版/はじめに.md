# ウマ娘 因子設計ボード（Androidのホーム画面アプリ版）

版：f2f0859b36（2026-09-24 07:56 作成）

このフォルダの中身をインターネット上に置くと、Androidスマホで「アプリとしてインストール」できます。
一度開けば、その後はオフラインでも動きます。

## 1. 公開する（最初の1回だけ・無料）
GitHub Pages を使う例です。

1. https://github.com にアカウントを作ってログイン
2. 右上の「＋」→「New repository」。名前は例えば `uma-inshi`、**Public** を選んで「Create repository」
3. 作ったページの「uploading an existing file」をクリックし、このフォルダの **7つのファイルすべて**
   （index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png / icon-maskable-512.png / はじめに.md）をドラッグ →「Commit changes」
4. 「Settings」→ 左の「Pages」→ Branch を **main**・**/(root)** にして「Save」
5. 1〜2分後、同じ画面の上に表示される `https://（ユーザー名）.github.io/uma-inshi/` が公開アドレスです

## 2. スマホに入れる
1. Androidの **Chrome** で上のアドレスを開く
2. 右上の「︙」→「**アプリをインストール**」（または「ホーム画面に追加」）
3. ホーム画面の「因子設計」アイコンから起動できます（オフラインでも可）

## 3. ツールを更新したとき
新しいこのフォルダの中身を、同じリポジトリに上書きでアップロードするだけです。
スマホ側は、次にネットにつながった状態で開いたときに自動で新しい版に入れ替わります（反映されないときはアプリを一度閉じて開き直してください）。

## スマホ版でできないこと
- 右上の「情報更新」（U-toolsから取り込む機能）はPC専用のため、スマホでは表示しません。データの更新はPCで行い、上の「3.」で入れ替えてください。
- 所持ウマ娘のチェック・保存した設計図は、スマホの中（このアプリ）だけに保存されます。PC版とは共有されません。
